PWNDA Wallet — Linux packages

Add the repository once; updates then arrive through your package manager.

Debian / Ubuntu

curl -fsSL https://pwndacreate.github.io/PwndaWallet/KEY.gpg | sudo tee /usr/share/keyrings/pwnda.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/pwnda.gpg] https://github.com/pwndaCreate/PwndaWallet/releases/download/linux-repo/ ./" | sudo tee /etc/apt/sources.list.d/pwnda.list
sudo apt update && sudo apt install pwnda-wallet

Fedora / RHEL

sudo curl -fsSL -o /etc/yum.repos.d/pwnda.repo https://pwndacreate.github.io/PwndaWallet/rpm/pwnda.repo
sudo dnf install pwnda-wallet
